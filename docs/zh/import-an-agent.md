# 导入 OpenClaw、Hermes 或 ChatGPT 智能体

从 OpenClaw、Hermes Agent 或 ChatGPT、Claude 等其他助理迁移？Doitx 可以将其转换为新的 Bot，连同其指令、记忆和技能，与你已有的 Bot 并存。

打开 **设置 → 通用**，选择 **导入智能体**。导入功能在 Web 应用和桌面应用中可用。

## 从 OpenClaw 或 Hermes 导入

选择任一方式：

- **选择文件夹**：智能体的主文件夹，例如 `~/.openclaw` 或 `~/.hermes`。
- **选择备份**：该文件夹的 `.zip` 或 `.tar.gz` 备份。

文件夹或备份在你的设备上读取。只发送导入所用的文件，并且只有在勾选 **包含 API 密钥** 时才会读取 `.env` 和 `auth.json`。

## 从其他助理导入

对于 ChatGPT、Claude、Gemini 或任何其他助理：

1. 选择 **复制提示**，并将提示发送给旧助理。它会要求该助理写下其名称、指令、它对你的记忆以及它遵循的流程。
2. 粘贴其回复并选择 **继续**，或者如果它给了你一个 `.md` 文件，选择 **选择文件**。

## 选择要导入的内容

在创建任何内容之前，你会看到导入找到的每个项目，并勾选要保留的内容：

| 项目 | 变为 |
| --- | --- |
| 指令（`SOUL.md`、`AGENTS.md`、…） | 新 Bot 的指令 |
| 记忆（`MEMORY.md`、`USER.md`、每日笔记） | Bot 的记忆，或所有 Bot 共享的记忆 |
| 技能 | 所有 Bot 共享的技能库中的技能 |
| 模型 | Bot 的模型（当你已连接该提供商或导入其密钥时） |
| MCP 服务器 | Bot 在使用前会询问的 MCP 服务器 |
| 计划任务 | 例程，在你启用之前处于暂停状态 |
| API 密钥 | 模型连接，仅当你勾选 **包含 API 密钥** 时 |

任何运行代码或自行行动的内容（技能、MCP 服务器、例程）默认不勾选，旧智能体写入的未修改默认值以及看起来包含密钥的文本也是如此。**未导入** 会列出被排除的内容及原因，例如只有旧运行时使用的文件。

## 导入之后

新 Bot 会打开一个清单，列出仍需要你处理的事项，例如 MCP 服务器所需的凭据或已暂停的例程。每个项目都会链接到你完成它的位置。你的其他 Bot（包括 Chief）不会更改。
