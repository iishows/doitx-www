# 快速开始

Doitx 为你提供持久化的 AI Bot。每个 Bot 都有自己的会话、记忆、例程和计算机，并可在 Web、桌面和移动应用上持续工作。

## 创建你的第一个 Bot

1. 登录 [app.doitx.ai](https://app.doitx.ai)，或参照[自托管指南](./self-host.md)运行你自己的实例。
2. 用通俗的话告诉 Bot 它的职责。它需要的其他信息会主动询问。

## 连接你的应用

Bot 可在你已经在用的应用中工作：Gmail、Slack、Notion、GitHub 以及[另外 1,400+ 个应用](/integrations/)。让 Bot 连接其中一个，并批准它发送给你的登录请求。

## 为它安排时间表

让 Bot 创建一个例程，例如“每个工作日早上 8 点，汇总我的收件箱”。Bot 会在自己的计算机上运行该例程，并在同一个对话中汇报结果。

## 导入你已有的智能体

来自 OpenClaw、Hermes 或其他助理？[将它导入](./import-an-agent.md)为一个新 Bot。
